Methodology

The catalogue is compiled from open data of the State List of Historical and Cultural Values. Names, addresses, categories and reference codes were not rewritten; only interface labels were translated. Text descriptions in object records are given in the original language.

The stories are written from official museum, memorial and government websites. Each story lists the sources used. If an official source did not provide a fact, we did not add it from memory.

If you find an inaccuracy, check the object record on heritage.gov.by and the official museum website. For educational work, the primary source always takes priority.
